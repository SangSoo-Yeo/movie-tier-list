# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
| --------- | --------------- | -------------------- | --------------------------- |
| AI 검토: 저장 기능이 없다 | 영화를 몇 장 옮기고 새 영화를 추가한 뒤 파일을 다시 열었더니 전부 미분류로 돌아가고 추가한 영화도 사라졌다 | 반영 | 기획서 완성 기준 '같은 파일을 다시 열어도 영화와 등급이 남습니다'를 지키지 못한다. 브라우저에 저장하고, 저장소를 쓸 수 없거나 내용이 깨져도 오류 없이 처음 목록으로 시작하게 하며, '처음으로'는 저장 내용도 함께 지우게 한다 |
| AI 검토: '처음으로'가 직접 추가한 영화를 지우지 않는다 | 영화를 추가한 뒤 '처음으로'를 눌렀더니 추가한 영화는 사라지고 처음 8편만 모두 미분류로 돌아왔다 | 보류 | 지적 자체가 사실과 달라 고칠 동작이 없다. 추가한 영화까지 지우고 처음 8편으로 돌아오는 것이 '처음으로' 버튼의 쓰임에도 맞다. AI가 코드를 실행하지 않고 추정해서 틀린 지적을 한 것으로 보인다. 다만 저장 기능을 넣은 뒤에는 이 버튼 한 번에 기록이 전부 사라지므로 확인 창을 넣는다(아래 '내가 찾은 것' 참고) |
| AI 검토: 빈 제목을 막지 않는다 | 제목을 비우거나 공백만 입력하고 '추가'를 눌렀더니 글자 없는 빈 카드가 생기고 안내 문구도 비어 있는 제목으로 나왔다 | 반영 | 기획서는 제목을 입력해야 카드가 생긴다고 읽힌다. 공백만 입력해도 카드를 만들지 않고 '제목을 입력해 주세요'라고 안내한다 |
| 동료: 휴대폰으로 열었더니 불편했다 | 브라우저 폭을 좁혀 보니 960px 고정 폭이라 오른쪽이 잘리고 가로로 밀어도 볼 수 없었다 | 반영 | 기획서 완성 기준 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'에 어긋난다. 폭을 '최대 960px, 화면 폭에 맞춤'으로 바꾸고 가로 스크롤을 막는 설정을 없앤 뒤, 좁은 폭에서 제목 영역·입력줄·등급 배지를 줄인다 |
| 동료: 카드 옮기는 게 처음엔 헷갈렸다 | 처음 화면에서 안내 문구가 작은 회색 글씨 한 줄뿐이라 놓치기 쉬웠고, 카드를 누른 뒤 등급을 다시 눌러야 하는 2단계 방식을 바로 알기 어려웠다 | 반영 | 안내를 눈에 띄게 하고, 선택된 카드를 더 분명하게 표시하고, 카드를 고르면 등급 칸이 눌러 달라는 모양으로 강조되게 한다 |
| 동료: 안 정한 영화가 맨 아래라 S칸까지 끌어 올리기 불편하다 | 카드를 S칸까지 끌어 올리려면 화면을 함께 올려야 해서 끌기가 번거로웠다 | 반영 | 문맥상 카드를 끌고 올라갈 때 화면이 따라 움직이지 않는 점을 말한 것으로 보이며, 끌기 동작의 실제 불편이라 타당하다. 미분류 영역을 아래에 두는 기획서 구성은 그대로 유지하고, 카드를 끌다가 화면 위쪽·아래쪽 가장자리에 가까워지면 화면이 자동으로 스크롤되게 한다 |
| 동료: 카드 색이 칙칙하다 | 카드가 회색 단색 그라데이션이라 등급 칸 색에 비해 밋밋해 보이는 것은 맞았다 | 반영 | 취향 문제이긴 하지만, 영화 카드가 이 화면의 주인공인데 등급 칸 색에 눌려 밋밋해 보이는 것은 사용감에 영향을 준다. 칸 색과 어울리는 부드러운 색을 카드에 적용하고, 글자 가독성이 떨어지지 않게 대비를 확인한다 |
| 동료: 영화 포스터 사진이 나오면 좋겠다 | 카드는 제목 글자만 표시하고 이미지를 넣을 자리가 없다 | 되묻기 | 포스터가 있으면 영화를 알아보기 쉽고 화면도 풍성해지므로 개선 가치는 있다. 다만 어떤 방식으로 넣느냐에 따라 구현 난이도와 파일 크기, 외부 의존이 크게 달라져서 방향을 먼저 확인한다. 질문: HTML 한 장은 유지하면서 이미지를 캐시에 추가하는 방식을 생각하신 건가요? 그렇다면 포스터를 처음 영화 8편에만 넣을지, 직접 추가한 영화에도 넣을지, 이미지를 HTML 안에 포함할지 외부 주소에서 불러올지(외부 주소는 '외부 파일 없이' 기준과 충돌) 알려 주세요 |
| 동료: C칸은 굳이 없어도 될 것 같다 | C칸은 낮은 평가를 둘 자리이고, 지우면 S·A·B 세 단계만 남아 취향 구분이 줄어든다 | 보류 | 칸을 줄이는 것이 더 나은 방향이라고 보기 어렵다. 이 티어리스트는 취향 정리가 목적이라 '별로였던 영화'를 구분해 두는 칸도 정보가 되고, 칸이 줄면 평가 폭도 좁아진다. 다만 '아쉬움'이라는 이름이 거슬렸다면 칸 이름을 바꾸는 정도는 나중에 검토할 수 있다 |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 좁은 화면에서 오른쪽이 잘릴 뿐 아니라 가로 스크롤 자체가 막혀 있어서(overflow-x 숨김) 잘린 내용에 접근할 방법이 전혀 없다. AI 검토는 '이 세 가지 외에는 잘 지킨다'고 했지만 이 완성 기준을 놓쳤고, 동료도 '불편'이라고만 했다.
  - 잘못 입력해 추가한 영화를 하나씩 지울 방법이 없다. 오타 하나를 고치려면 '처음으로'로 전체를 초기화해야 하므로, 추가한 카드에 삭제 기능을 넣고 삭제 전에 확인을 받는다.
  - 60자까지 입력되는 긴 제목이 크기가 고정된 카드(96×128px) 밖으로 넘친다. 카드 안에서 줄이거나 말줄임표로 처리하고, 전체 제목은 마우스를 올리면 볼 수 있게 한다.
  - 저장 기능을 넣은 뒤에는 '처음으로' 한 번에 모든 기록이 사라지므로 확인 창을 넣는다.
