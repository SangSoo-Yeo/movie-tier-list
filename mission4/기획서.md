# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.
- 영화마다 한 줄 메모를 남기고, 정리한 결과를 텍스트로 내보내 친구들과 나눕니다.

## 화면과 동작

### 기본 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다. 빈 제목과 이미 있는 제목은 추가하지 않고 안내 문구를 보여 줍니다.
- 영화 목록, 등급 배치, 메모를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다. 이때 메모와 검색 상태도 함께 처음으로 돌아갑니다.

### 영화 개수 보기

- 입력란 아래에 “전체 영화 N개 · 등급 정함 N개 · 아직 안 정함 N개”를 보여 줍니다.
- S·A·B·C 각 등급 글자 아래에 그 칸의 영화 개수를, “아직 안 정한 영화” 제목 옆에 미분류 개수를 보여 줍니다.
- 개수는 검색 결과와 관계없이 전체 영화 기준이며, 카드를 옮기거나 영화를 추가하거나 ‘처음으로’를 누르면 바로 바뀝니다.

### 제목으로 영화 찾기

- 검색창은 평소에 숨겨져 있고, ‘검색’ 버튼을 누르면 나타납니다. 다시 누르면 닫힙니다.
- 검색어를 입력하는 즉시 제목에 검색어가 포함된 카드만 보여 줍니다. 영문은 대소문자를 구분하지 않습니다.
- 검색 중에는 “검색 결과 N개” 또는 “해당하는 영화가 없어요” 문구를 보여 줍니다.
- ‘메모도 검색’ 체크박스를 켜면 메모 내용도 함께 찾습니다. 기본값은 꺼짐이며, 켜면 결과 문구에 “(제목·메모)”를 표시합니다.
- 검색은 카드를 가리기만 하며 영화 목록과 등급을 바꾸지 않습니다. 검색어는 저장하지 않습니다.
- 검색창을 닫거나, 영화를 추가하거나, ‘처음으로’를 누르면 검색어를 비우고 전체 영화를 다시 보여 줍니다. 검색창을 닫으면 ‘메모도 검색’ 선택도 꺼집니다.

### 카드에 한 줄 메모 달기

- 모든 카드 아래에 메모를 보여 줍니다. 메모가 없으면 ‘+ 메모’가 보입니다.
- 메모나 ‘+ 메모’를 누르면 그 자리에서 입력창으로 바뀝니다. 메모는 최대 40자이며, 입력 중에는 “12/40”처럼 글자 수를 보여 줍니다.
- Enter를 누르거나 입력창 바깥을 누르면 저장하고, Esc를 누르면 취소합니다. 비우고 저장하면 메모가 삭제됩니다.
- 한글을 입력하는 도중(글자 조합 중)에 누른 Enter는 저장하지 않습니다.
- 편집 중인 카드는 끌 수 없습니다. 메모를 누르는 동작이 카드 선택으로 이어지지 않습니다.
- 다른 카드의 메모를 편집하기 시작하면 앞서 편집하던 내용은 먼저 저장됩니다.
- 키보드로는 카드에 포커스를 두고 F2를 누르면 메모 편집이 열립니다. 저장하거나 취소한 뒤에는 포커스가 그 카드의 메모 버튼으로 돌아옵니다.
- 카드를 선택하거나 옮겨 화면이 다시 그려져도 키보드 포커스가 사라지지 않습니다.
- 메모가 3줄을 넘어 잘리면 ‘펼치기’ 버튼이 나타나고, 누르면 전체를 보여 줍니다(‘접기’로 되돌림). 메모 전체 내용은 마우스를 올렸을 때도 볼 수 있습니다. 펼친 상태는 저장하지 않습니다.
- 메모는 카드를 옮겨도 그 카드를 따라가며, 영화 데이터와 함께 저장됩니다. 메모가 없던 이전 저장 데이터도 그대로 불러옵니다.

### 끌 때 자동 스크롤

- 카드를 끄는 동안 마우스가 화면 위쪽이나 아래쪽 가장자리(약 90px 이내)로 가면 화면이 자동으로 스크롤됩니다. 가장자리에 가까울수록 빠르게 움직입니다.
- 카드를 놓거나 끌기를 마치면 자동 스크롤도 멈춥니다.
- 마우스로 끄는 경우를 기준으로 하며, 터치 화면에서는 카드를 선택한 뒤 등급 글자를 눌러 옮깁니다.

### 목록 내보내기

- ‘목록 복사’를 누르면 정리한 목록을 텍스트로 클립보드에 복사합니다. 복사하지 못하면 안내 문구를 보여 줍니다.
- ‘txt 저장’을 누르면 같은 내용을 `영화_티어리스트.txt` 파일로 저장합니다(UTF-8).
- 검색 중이어도 가려진 영화까지 전체 영화를 내보냅니다. 내보내기는 영화 목록과 화면 상태를 바꾸지 않습니다.
- 내용은 S, A, B, C, 아직 안 정한 영화 순서로 등급별 개수와 영화 제목, 메모를 담습니다. 영화가 없는 등급은 ‘(없음)’으로 표시합니다.

```
내 영화 티어리스트

S 등급 (0개)
- (없음)

A 등급 (1개)
- 인터스텔라 — 우주 최고

B 등급 (0개)
- (없음)

C 등급 (0개)
- (없음)

아직 안 정한 영화 (7개)
- 기생충
- 라라랜드
...
```

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 이번에 하지 않는 것

- 메모 삭제나 카드 이동을 되돌리는 기능
- 여러 탭 사이의 자동 동기화
- 터치 화면에서의 끌어 놓기 지원
- 여러 기기 간 동기화, 계정별 저장, 친구와 함께 편집(서버나 로그인이 필요하므로 제외)

## 완성 기준

### 기존 기준(그대로 유지)

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다. 메모, 메모 편집 중, 검색창, 버튼 줄이 있는 상태에서도 같습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다. 메모는 모두 사라지고 검색창은 닫힙니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.

### 추가 기준

- 영화 개수(전체, 등급 정함, 아직 안 정함, 각 등급)가 실제 카드 수와 일치하고, 옮기기·추가·‘처음으로’ 뒤 바로 갱신됩니다.
- 검색창은 평소에 숨겨져 있고 ‘검색’ 버튼으로 열고 닫을 수 있습니다.
- 검색하면 조건에 맞는 카드만 보이고, 검색을 닫으면 전체 영화가 다시 보입니다. 검색은 영화 목록과 등급을 바꾸지 않습니다.
- ‘메모도 검색’은 기본이 꺼져 있어 제목만 찾고, 켜면 메모 내용도 찾습니다.
- 메모는 40자 이내로 카드 바로 아래에 보이며, 저장·수정·삭제할 수 있습니다.
- 메모는 카드를 옮겨도 따라가고, 같은 브라우저에서 다시 열어도 남습니다. 메모가 없는 이전 저장 데이터도 정상으로 열립니다.
- 한글 입력 중 Enter로 메모가 잘못 저장되지 않습니다. 편집 중에는 카드가 끌리지 않습니다.
- 카드를 끌 때 화면 위·아래 가장자리에서 자동으로 스크롤되고, 놓으면 멈춥니다.
- ‘목록 복사’와 ‘txt 저장’이 검색 여부와 관계없이 전체 영화를 등급별로 메모와 함께 내보내며, 영화 목록을 바꾸지 않습니다.
