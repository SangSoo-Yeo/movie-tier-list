# 영화 티어리스트 웹페이지 기획서

## 1. 개요

내가 본 영화를 S부터 F까지 6단계 등급으로 나누어 배치하고, 모임에서 친구들과 같은 화면을 보며 이야기하기 위한 웹페이지입니다.

## 2. 사용자와 목적

- 사용 상황: 모임에서 노트북 또는 PC 모니터 한 화면을 함께 보면서 사용
- 핵심 목적: 친구와의 대화 소재로 활용 (등급 배치를 두고 이야기하는 것이 중심)

## 3. 화면 구성

### 3.1 티어 영역
- 등급은 S, A, B, C, D, F 6단계이며, 위에서 아래로 한 줄씩 가로로 배치합니다.
- 각 등급 줄은 등급 이름이 적힌 라벨과 카드를 놓는 칸으로 구성합니다.

### 3.2 미분류 영역
- 아직 등급을 정하지 않은 영화 카드를 모아 두는 칸입니다.
- 처음 열었을 때 8편이 모두 이 칸에 있습니다.

### 3.3 영화 카드
- 첫 버전은 포스터 없이 영화 제목이 적힌 카드로 만듭니다.
- 이후 영화별로 포스터 이미지를 넣을 수 있는 구조로 설계합니다.
- 포스터는 저작물이므로 임의로 가져와 넣지 않으며, 사용자가 준비한 이미지 파일을 사용합니다.
- 큰 모니터에서 멀리서도 제목이 읽히도록 글자 크기를 충분히 크게 합니다.

### 3.4 상단 기능 버튼
- 영화 추가
- 영화 삭제
- 초기화 (배치만 초기화)

### 3.5 디자인 방향
디자인은 제가 임의로 정한 안이며, 제작 후 화면을 보고 바꿀 수 있습니다.

- 전체 분위기: 영화관을 연상시키는 어두운 배경에, 밝은 글자와 선명한 등급 색상을 사용하는 다크 테마
- 바탕색: 짙은 남색 계열의 검정 (#14161C)
- 카드와 칸 색상: 바탕보다 한 단계 밝은 짙은 회청색 (#232733), 글자는 거의 흰색 (#F5F5F7)
- 등급별 색상(등급 라벨 배경):

| 등급 | 색상 | 색상 코드 |
| --- | --- | --- |
| S | 붉은색 | #E5484D |
| A | 주황색 | #F08C3A |
| B | 노란색 | #E9C53B |
| C | 초록색 | #5BB974 |
| D | 파란색 | #4A90D9 |
| F | 보라색 | #8E7CC3 |

- 등급 라벨의 글자는 어두운 색을 써서 밝은 라벨 위에서도 잘 읽히게 합니다.
- 글꼴은 한글이 또렷한 고딕 계열을 쓰고, 등급 글자와 카드 제목은 큼직하게 표시합니다.
- 카드를 끌 때와 놓을 칸 위에 올렸을 때는 테두리나 밝기 변화로 상태를 알 수 있게 합니다.

## 4. 동작

| 기능 | 설명 |
| --- | --- |
| 드래그 앤 드롭 | 카드를 끌어서 원하는 등급 줄이나 미분류 칸에 놓습니다. |
| 버튼 선택 | 카드를 클릭하면 S~F 및 미분류 버튼이 나타나고, 누르면 해당 칸으로 이동합니다. |
| 영화 추가 | 별도의 영화 추가 버튼을 누르고 영화 제목을 입력하면 새 카드가 미분류 칸에 생깁니다. |
| 영화 삭제 | 별도의 영화 삭제 버튼으로 카드를 삭제합니다. 실수 방지를 위해 삭제 전 확인 절차를 둡니다. |
| 포스터 추가 | 카드에서 포스터 추가를 선택하고 사진 파일을 업로드하면, 해당 카드가 제목 카드에서 포스터 카드로 바뀝니다. |
| 자동 저장 | 배치를 바꿀 때마다 현재 사용 중인 기기의 브라우저에 저장하고, 다시 열면 그대로 불러옵니다. |
| 초기화 | 배치만 초기화합니다. 버튼을 누르면 모든 카드가 미분류로 돌아가며, 추가하거나 삭제한 영화 목록은 그대로 유지됩니다. 실행 전 확인 절차를 둡니다. |

## 5. 필요한 자료

### 5.1 영화 목록 (기본 8편)
1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

### 5.2 포스터 이미지
- 처음에는 포스터 없이 제목 카드로 시작합니다.
- 포스터는 사용자가 사진 파일을 업로드하는 방식으로 영화 카드에 추가합니다.
- 업로드할 이미지 파일은 사용자가 직접 준비합니다. 포스터는 저작물이므로 임의로 가져와 넣지 않습니다.

## 6. 저장 방식과 한계

- 저장 위치는 사용 중인 기기의 브라우저입니다.
- 같은 기기, 같은 브라우저에서 다시 열면 배치가 유지됩니다.
- 다른 기기나 다른 브라우저, 다른 사람의 화면에는 반영되지 않습니다.
- 브라우저 데이터를 삭제하면 저장된 배치도 사라질 수 있습니다.

## 7. 완성 기준

1. 8편의 영화 카드를 S~F 등급으로 옮길 수 있습니다. 드래그 앤 드롭과 버튼 선택 두 방식이 모두 동작합니다.
2. 페이지를 닫았다가 다시 열어도 배치가 유지됩니다.
3. 초기화 버튼을 누르면 모든 카드가 미분류로 돌아가며, 추가하거나 삭제한 영화 목록은 유지됩니다.
4. 큰 모니터에서 카드 제목과 등급 글자가 잘 보입니다.
5. 별도의 버튼으로 영화를 추가하고 삭제할 수 있습니다.
6. 사진 파일을 업로드해 영화 카드에 포스터를 추가할 수 있습니다.

## 8. 아직 정하지 않은 사항

- 현재 남아 있는 미결 사항은 없습니다. 디자인 방향은 3.5에 정리한 안을 기준으로 하며, 제작 후 수정할 수 있습니다.

## 9. 범위 밖 (이번 버전에서 하지 않는 것)

- 여러 사람이 각자 다른 기기에서 동시에 편집하는 기능
- 로그인 및 서버 저장
- 포스터 이미지 자동 검색 및 자동 삽입
- 티어표를 이미지 파일로 저장하는 기능
